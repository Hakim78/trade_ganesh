# Décisions d'architecture

Une ligne par décision, datée, ajoutée en bas. Règle de `CLAUDE.md` (section Conventions).

- 2026-09-11 — Skills tiers installés dans `.claude/skills/` (emplacement projet, commités) après revue de sécurité de chaque `SKILL.md` et de chaque script ; inventaire, rejets et résultats dans `.claude/skills/README.md`.
- 2026-09-11 — Chaque skill tiers reçoit en tête une note « Adaptation projet » (marché US, yfinance, `config.yaml`, QuantStats) plutôt qu'une réécriture : les mises à jour amont restent faciles à réappliquer.
- 2026-09-11 — Templates exécutables `vectorbt-expert/rules/assets/*.py` retirés (lecture de clés API dans l'environnement, appels OpenAlgo, marché indien) ; seules les fiches Markdown sont conservées.
- 2026-09-11 — Hook git `pre-commit` maison dans `.claude/hooks/` (celui de shakeebshaan/claude-code-quant-skills est cité dans son README mais absent du dépôt) ; activé par `git config core.hooksPath .claude/hooks`, à refaire à chaque clone.
- 2026-09-11 — Aucun skill Alpaca tiers retenu (les trois marqués Alpaca sont des outils discrétionnaires, deux lisent des secrets) : la boucle live paper (Phase 5) sera écrite avec `alpaca-py`, endpoint `paper-api.alpaca.markets` vérifié par `tests/test_paper_only.py`.
- 2026-09-11 — Tearsheet : QuantStats (`outputs/tearsheet.html`), pas OpenStatz ni le générateur privé du skill HyperFrequency.
- 2026-09-11 — Indicateurs implémentés en pandas/numpy dans `strategy/strategy.py` (ni `openalgo.ta`, ni TA-Lib) pour garder la stratégie pure et sans dépendance broker ou marché.
- 2026-09-11 — Sorties des scripts de skills dans `reports/` (gitignored) ; sorties du projet dans `outputs/` (gitignored) ; données brutes dans `data/` (gitignored).
- 2026-09-11 — Dépôt distant : https://github.com/Hakim78/trade_ganesh (branche `main`).
- 2026-09-15 — Stratégie source = script Pine v5 de l'ami, conservé verbatim dans `docs/STRATEGY_SOURCE.pine` ; `docs/STRATEGY.md` en est la traduction règle par règle. En cas de divergence, le Pine fait foi après validation de l'ami. Les points non déductibles du script (symbole, timeframe, unité TP/SL, fuseau horaire) sont marqués À CONFIRMER et bloquent le code.
- 2026-09-16 — Symbole choisi par Hakim/Claude à la place de l'ami : **QQQ** (Nasdaq-100 ETF) en 5 min, bougies de séance uniquement. Motifs : paper trading Alpaca possible (invariant 6), historique minute gratuit, cohérent avec « NASDAQ » du doc. SPY en instrument secondaire de généralisation. Réversible via `config.yaml` → `instrument`.
- 2026-09-16 — TP/SL : `tpPoints = 30` / `slPoints = 15` interprétés comme des **points d'indice Nasdaq-100** (nom des variables, valeurs rondes), convertis en fraction du prix via `exits.index_reference = 24000` (0,125 % / 0,0625 %). L'alternative « ticks » de `strategy.exit` donnerait 0,30 $ / 0,15 $ sur QQQ, sous le bruit d'une bougie de 5 min : rejetée. À faire valider par l'ami.
- 2026-09-16 — Filtre horaire `14 <= hour < 18` lu en **UTC** (graphique broker en UTC, cohérent avec le nom nySession = matinée de New York : 10h–14h ET en été). Configurable via `strategy.session_filter`. À faire valider par l'ami.
- 2026-09-16 — VWAP ancré à l'ouverture de séance 09:30 ET (`ta.vwap` sur un graphique QQQ sans extended hours). Coûts : 0,01 % de frais + 0,01 % de slippage par côté, justifiés dans `config.yaml`.
- 2026-09-16 — Données : yfinance (60 jours, sans clé) pour la fenêtre de mise au point ; Alpaca (clés gratuites) pour l'étude in-sample 2018–2024 / out-of-sample 2025-01 → 2026-06 figée dans `docs/HYPOTHESIS.md`. La fenêtre de mise au point est hors étude.
- 2026-09-16 — Frontend : React (Vite + TypeScript) avec lightweight-charts, lit `outputs/dashboard.json` produit par le backtest et `outputs/live/state.json` produit par le live. Servi par nginx dans Docker, sans backend.
- 2026-09-16 — Exécution du backtest par un exécuteur maison (`backtest/engine.py`) : `vbt.Portfolio.from_signals` (vectorbt 1.1.0 installé) n'évalue les stops qu'à partir de la bougie suivant l'entrée, alors que TradingView les active dès la bougie d'entrée ; avec un SL de 0,06 % en 5 min, la différence dénature la stratégie. VectorBT reste utilisé pour les ratios sur rendements journaliers (`backtest/report.py`). Sémantique couverte par `tests/test_execution.py`.
- 2026-09-16 — plotly épinglé < 6 : vectorbt 1.1.0 plante à l'import avec plotly 7 (`scattermapbox` retiré).
